# 📚 Online Book Store

A modern Online Book Store web application built using **Java, JSP, Servlets, MySQL, HTML, CSS, and Tomcat**.  
This project allows users to browse books, register/login, and simulate online purchases using a QR payment system.

---

## 🚀 Features

✨ User Registration & Login  
✨ Admin & User Role Management  
✨ Add / Remove Books  
✨ Responsive UI Design  
✨ QR Code Payment Page  
✨ Cloud Database Integration  
✨ Session Management  
✨ Dynamic Book Display  
✨ Online Deployment using Render + TiDB Cloud

---
